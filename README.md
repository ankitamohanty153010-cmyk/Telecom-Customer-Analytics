# Telecom Customer Analytics

## Project Overview

This project analyzes telecom customer network usage, handset information, and application traffic using Python.

The objective is to understand customer usage patterns, device popularity, network traffic, and application consumption, and to generate business insights that can support network optimization and customer-focused decision-making.

## Objectives

- Analyze telecom customer network usage.
- Identify the most commonly used handset manufacturers and models.
- Analyze total traffic generated by different applications.
- Identify important relationships between numerical variables.
- Generate business insights and recommendations from the analysis.

## Dataset

The dataset contains telecom customer usage information, including:

- Customer and network information
- Handset manufacturer and handset type
- Download and upload traffic
- Application-level traffic
- Network usage and activity information

The project also includes a field description file to understand the dataset variables.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Analysis Process

### 1. Data Loading and Understanding

The dataset was loaded using Pandas and examined to understand its structure, columns, data types, and available records.

### 2. Data Cleaning

The data was prepared for analysis by handling missing values and preparing numerical and categorical variables.

### 3. Exploratory Data Analysis

The following analyses and visualizations were performed:

- Histograms
- Boxplots
- Correlation heatmap
- Scatter plot
- Bar charts
- Handset manufacturer analysis
- Handset type analysis
- Application traffic analysis

## Key Findings

- Apple, Samsung, and Huawei are the most widely used handset manufacturers.
- Huawei B528S-23A is the most commonly used handset model.
- Several numerical variables show skewed distributions and outliers.
- The correlation analysis identified relationships between selected network-related variables.
- Total Download and Total Upload traffic do not show a strong relationship.
- Gaming and Other applications generate the highest amount of network traffic.
- The analysis highlights opportunities for better bandwidth allocation and network planning.

## Business Recommendations

- Increase network capacity for high-traffic applications such as Gaming and Other services.
- Optimize network resources during peak traffic periods.
- Continuously monitor application traffic trends to improve Quality of Service (QoS).
- Focus customer support and software optimization on commonly used handset manufacturers and models.
- Improve data collection processes to reduce missing or undefined handset information.
- Use customer usage patterns to support future marketing and service planning.
